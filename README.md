# Ethiopian Travel Platform

A tourism web application for exploring destinations across Ethiopia. The current codebase uses Django and is planned for an upgrade to a React frontend, Django REST Framework API, and PostgreSQL database.

## Current stack

- Python
- Django
- SQLite (existing local development database)
- HTML, CSS, Django templates

## Planned improvements

- React + Vite frontend
- Django REST Framework API
- PostgreSQL database
- Destination browsing and detail pages
- User authentication and booking workflow
- Clearly labeled simulated payments
- Automated tests and deployment documentation

## Local setup

Setup instructions will be added after the dependency list and project configuration are reviewed and updated.

## Security note

Do not commit `.env` files, database files, credentials, API keys, or production secret keys.
